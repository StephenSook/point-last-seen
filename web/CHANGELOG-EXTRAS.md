- Fix: a segment's shape could be accepted with a ring that was not closed or with a position off the earth. One latitude out of range drew non-finite positions in the cube while its gate still passed. Every ring must now end where it starts, and every position must have a longitude from -180 to 180 and a latitude from -90 to 90, in a Polygon and in each part of a MultiPolygon. A centroid off the earth is refused by the field type check, which names `segment.centroid.lat`. Source: review (second-model review round 3, medium). Verified: the new test (an open ring, a latitude of 91, a longitude of 181, and two MultiPolygons with one bad part, plus a good MultiPolygon that must pass) failed first, then the extras unit tests pass 174; the judge and cube browser checks pass 8 of 8; web typecheck exit 0; `bash scripts/ci-local.sh` exit 0.

- Fix (privacy and stability): the public run reader checked field names but not their values. A camera sighting sent as a list (one carrying private evidence) was accepted, and a camera time sent as an object threw before the judge page's panel boundaries could catch it. A new module, `runSchema.ts`, gives every field the contract lists its type: text, number, true or false, an exact value, a list of a type, or an exact object shape (a position, a camera reading, an assignment). The reader checks every field that is present and refuses the first wrong one by name ("The run has a field of the wrong type: event.reading.sighting."). A team or device that is not an object now refuses too, where before it was skipped. Which fields must be present is unchanged. Camera times must be text, but their format is not enforced: a bad time already draws nothing. Source: review (second-model review round 3, high). Verified: the new test (fifteen wrong-type cases across every part, including one that used to throw) failed first, then the extras unit tests pass 173; the extras browser checks pass 38 of 38; web typecheck exit 0; `bash scripts/ci-local.sh` exit 0.

- Fix (privacy): a place to check written as "destination " (with a trailing space) skipped the rule that refuses its home position, because the reader took any string as a report's kind. The reader refuses any other value, with no trimming or case folding. A type-level test checks that each list names every value the engine allows. Source: review (second-model review round 3, high). Verified: the new test (eight wrong spellings and unknown values) failed first, then the extras unit tests pass 172; removing "plan_ack" from the list makes the web typecheck fail, and restoring it passes; the judge and cube browser checks pass 8 of 8; `bash scripts/ci-local.sh` exit 0.
