Plans where to search for a missing person, and updates the map as reports come in.

Point Last Seen is a search command post for finding a person living with dementia who has wandered, with an iPhone app for searchers and an Android app for the family.

This version runs practice searches only. Nobody is missing in a practice search. If someone is missing now, call 911.
