- **A phone's first publish no longer replaces the shared profile.** Before, a phone with no record of what it published (a reinstall, a second family phone, cleared storage) wrote profile/shared and profile/command whole, erasing command's edits, another phone's tracking answer and any field a newer schema adds. - **Every newer build installs as an update.** `versionCode` is now the HEAD commit's time in epoch seconds (`git log -1 --format=%ct`, read through `providers.exec`), so it rises with each commit; a shallow CI checkout still has its HEAD commit, and with no git at all the build falls back to 1. `android/check-version-code.sh <apk>` reads the APK's versionCode with aapt2 and fails unless it equals the HEAD commit time; `android/release.sh` now runs it on the signed file. Source: review (a fixed versionCode of 1 gave every build the same version).
