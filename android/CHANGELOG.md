Newest first. Each entry: what changed, its source, how it was verified.

## Unreleased

- **The phone-number rule runs until the text stops changing.** One pass of the rule could leave a run that a second pass reads differently: "Seen 11/19/2026 12:12 5:55 01:42" kept "Seen 11/19/2026 12:" beside the removed number, and a second pass removed that too. This app scrubs saved text again on every profile save and on a remembered note's label, so what was shown and what was saved could differ. Following the shared rule, `PhoneNumbers.remove` now runs the rule until a pass changes nothing, at most 4 passes in all; if it never settles it keeps the 4th pass's text (the most scrubbed) and logs one fixed line with no note text. Source: review.
